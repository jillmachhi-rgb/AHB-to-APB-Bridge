# AHB-to-APB-Bridge
UVM-Based Functional Verification of an AHB-to-APB Bridge

Overview
This project focuses on verifying an AHB-to-APB Bridge using SystemVerilog and Universal Verification Methodology (UVM). The bridge enables communication between high-performance AHB and low-power APB peripherals.

Objectives
Verify read and write transactions.
Check correct address and data transfer.
Verify reset behavior.
Use a scoreboard and functional coverage to evaluate verification scenarios.

Technologies Used
Verilog / SystemVerilog
UVM (Universal Verification Methodology)
AMBA AHB-Lite and APB protocols
QuestaSim / ModelSim or another compatible simulator

Verification Scenarios
Read transaction
Write transaction
Reset operation
Randomized transactions
